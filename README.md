# blockbilanz-media

Öffentliche Ablage für Bilder geplanter Blockbilanz-Beiträge auf Instagram und X.

Buffer lädt das Bild erst zum Veröffentlichungszeitpunkt und braucht dafür eine
dauerhaft erreichbare HTTPS-Adresse. Dieses Repo liefert sie über
`https://raw.githubusercontent.com/3Blocks-net/blockbilanz-media/main/<pfad>`.

Hier liegen ausschließlich Bilder, die ohnehin öffentlich gepostet werden.
Keine Entwürfe, keine Kundendaten, keine internen Unterlagen.

Die Dateien erzeugt und veröffentlicht das Bildkit im Marketing-Repo
(`3Blocks-net/blockbilanz-marketing`, Ordner `bildkit/`). Nichts hier von Hand
bearbeiten: eine Adresse, die Buffer schon kennt, darf sich nicht ändern.
